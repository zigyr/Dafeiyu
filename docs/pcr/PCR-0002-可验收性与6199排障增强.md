## 1. 背景与问题

PCR-0001 建立了工程化基线，但控制台的验收仍有两个现实障碍：

1. **Agent 执行环境无法访问 WSL**（`wsl.exe` 返回 `Wsl/E_ACCESSDENIED`），
   无法在开发侧完成一次真实的 NapCat / QQ 启动验收；只能请用户在本机运行，
   再靠截图或口述反馈，信息不完整。
2. 交接文档的「已知风险」里列着 **Windows 防火墙拦截 6199**，
   但旧诊断面板只能“看”，不能一键处理；用户需要自己打开管理员命令行手动加规则。
3. 诊断面板的检查结果无法直接复制，用户反馈时需要手抄。

不解决的影响：真实环境问题定位慢；6199 不通时用户容易卡住；
每条反馈都缺少完整的 WSL / WebUI / QQ 状态上下文。

## 2. 需求提炼

- **原始诉求**：用户指示「继续下一步」，结合交接文档待办与已知风险推进。
- **问题陈述**：缺少可导出的真实环境诊断；缺少 6199 防火墙的一键放行。
- **目标（可验证）**：
  1. 新增 `app.py --diagnose`，无界面输出完整报告并保存到 `logs/`。
  2. 诊断面板支持「复制结果」，复制内容包含失败项与建议。
  3. 诊断面板在「WSL → Windows 6199」失败时显示「放行 6199」，
     通过 UAC 调用 `netsh` 添加入站规则。
  4. 不改变一键启动、登录、托盘、界面布局的既有行为。
- **非目标**：
  - 不自动修改防火墙（必须用户点击并确认 UAC）。
  - 不改变 OneBot token / 端口 / WSL 发行版等配置结构。
  - 不加入新的第三方依赖。
  - 不做真实 QQ 回归（仍需用户本机环境）。

## 3. 范围与影响

| 类型 | 内容 |
| --- | --- |
| 新增 | `console/app.py` 的 `_run_diagnose()` / `--diagnose`；`core.Backend.allow_firewall()`；`Service.allow_firewall()`；诊断面板「复制结果」「放行 6199」 |
| 修改 | `core.WSL.read()` 失败时返回空串，避免把 WSL 错误文本当 JSON；`WebUI._read_cfg()` 错误文案区分「找不到」与「读取失败」；README 调试/诊断章节 |
| 移动 / 删除 | 无 |
| 数据 / 配置 | 不修改 `settings.json` 结构；不写入 token |
| 依赖 | 仅使用标准库 `ctypes` 与系统 `netsh`，无新增 pip 依赖 |
| 安全 | 防火墙规则仅放行 TCP 6199 入站；需 UAC；不保存密码 |
| 文档 | 本 PCR、`使用说明.md`、`任务交接文档.md`、PCR 索引 |

## 4. 方案与取舍

| 方案 | 说明 | 取舍 |
| --- | --- | --- |
| A（采纳） | CLI 诊断 + 面板复制 + 按需 UAC 放行 6199 | 无界面也能验收；危险操作仍由用户确认 |
| B | 启动时自动加防火墙规则 | 会静默改系统，且可能每次弹 UAC，不采纳 |
| C | 只在文档里写手动 `netsh` 命令 | 用户仍需切管理员终端，体验差 |
| D | 在应用内嵌密码 / 自动提权服务 | 安全风险高，超出范围 |

## 5. 实施计划

1. `core.py`：增加 `allow_firewall()` / 规则检测；修正 `WSL.read()` 与 WebUI 错误文案。
2. `app.py`：增加 `--diagnose`，输出状态、检查项、日志尾部，并写入 `logs/diagnose-*.txt`。
3. `service.py` / `demo.py`：增加 `allow_firewall()` 的线程池封装与演示实现。
4. `ui.py`：诊断面板增加复制、放行按钮；仅在 6199 可达性失败时显示放行。
5. 更新 `使用说明.md`、PCR 索引与交接文档，验证后提交。

## 7. 风险与回滚

| 风险 | 概率 / 影响 | 缓解 | 回滚 |
| --- | --- | --- | --- |
| 用户误点放行，扩大入站面 | 低 / 中 | 仅放行 TCP 6199，规则名固定；需 UAC；按钮仅在检测失败时出现 | `netsh advfirewall firewall delete rule name="Dafeiyu OneBot 6199"` |
| `netsh` 路径 / 本地化输出导致检测失败 | 低 / 低 | 使用绝对路径与固定英文规则名 | 手动添加规则 |
| 诊断命令在 WSL 不可用时耗时长 | 中 / 低 | 各检查均有超时；CLI 可分步观察输出 | 直接关闭命令 |
| `WSL.read` 改为失败返回空串影响其他读取 | 低 / 低 | 调用方均有空值兜底 | `git revert` 对应提交 |
