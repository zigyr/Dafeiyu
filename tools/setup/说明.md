# 一次性运维脚本（归档）

本目录收纳原先散落在 `astrbot/` 根目录的一次性脚本。它们**不参与**控制台
（`console/app.py`）的运行时，只在需要排查或配置 AstrBot 时手工执行。

## 运行前提

- AstrBot 已启动，控制台可访问 `http://127.0.0.1:6185`（默认 dashboard 端口）。
- 使用与控制台相同的 Python 环境（PySide6 环境即可，脚本只用标准库）。
- 凭据一律通过环境变量传入，脚本中不再保存密码或密钥：

```powershell
$env:ASTRBOT_PWD = "<AstrBot 控制台密码>"
$env:TOKENRHYTHM_API_KEY = "<模型服务密钥>"   # 仅 test_llm*.py / fix_provider.py 需要
F:\Compilers\python3\python.exe F:\dafeiyu\tools\setup\test_llm.py
```

## 脚本清单

| 分组 | 脚本 | 用途 |
| --- | --- | --- |
| QQ 空间插件 | `install_qzone.py`、`install_qzone2.py`、`install_qzone3.py` | 安装 `astrbot_plugin_qzone_publish` 的迭代版本 |
| | `check_qzone_plugin.py` | 检查插件是否安装、版本与启用状态 |
| | `config_qzone.py` | 写入插件配置 |
| | `find_qzone.py` | 定位插件目录与配置 |
| 配置排查 | `inspect_config.py`、`inspect_config2.py` | 读取并打印 AstrBot 配置结构 |
| | `fix_provider.py` | 修复 LLM Provider 配置 |
| 人设 | `setup_persona.py`、`set_persona_active.py` | 创建 / 切换人设 |
| LLM 连通性 | `test_llm.py`、`test_llm_raw.py` | 测试模型调用链路 |

## 注意

- 这些脚本是历史迭代产物，存在功能重叠（如 `install_qzone*.py`），保留用于追溯，不建议继续扩展。
- 执行前先确认目标环境，避免把测试配置写入正在使用的 AstrBot。
